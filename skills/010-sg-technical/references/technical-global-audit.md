# Technical Global Audit

Discover code-applicable projects, ask the operator to select scope when needed, and run the project audit contract independently for each selected project. Each sub-audit is read-only except for authorized operational records. Aggregate scores, cross-project patterns, severity and evidence limits; never infer a fix authorization from the aggregate.
