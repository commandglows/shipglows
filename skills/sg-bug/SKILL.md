# sg-bug

Resolve the affected product and surface, load `$SHIPGLOWS_ROOT/skills/references/intent-to-outcome-autonomy.md`, and own the defect until proportional proof exists. Do not ask the operator to schedule reproduction, implementation, or verification stages.

Load `../003-sg-bug/SKILL.md` for the full bug lifecycle. Treat `003-sg-bug` as an expert/legacy engine, not the public name.

`fix` is the canonical repair mode. `shipglows fix <defect>` is only a short
route to `sg-bug fix <defect>`; this public owner still decides whether the
bounded `106-sg-fix` path is sufficient or the full bug lifecycle is required.
