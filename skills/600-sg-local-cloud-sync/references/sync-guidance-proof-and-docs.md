# Sync Guidance Proof And Docs

On failure stop blocking feedback, retain only safely retryable work, distinguish offline/provider/auth/payload/conflict/account mismatch, and never leak private payloads/tokens/cookies. Prove empty snapshot detection, same-account reuse, different-account replay block, allowed signup seeding, existing-cloud hydration, queue flush-before-seed, coalescing/retry, invalid-record rejection, stage order and reload-ready notice.

Provider behavior requires current official documentation. Block shipment for spinner-only feedback, fake stage completion, silent wipe, cross-account queue replay, unvalidated payload, stale-auth flush, vague merge policy, sensitive sync, unexplained reload or unsupported recovery promise. Review public sync/backup claims, pricing, privacy/retention, account support, troubleshooting, screenshots and QA.
