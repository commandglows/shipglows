# sg-private

## Mission

`sg-private` is the public owner for explicit private-memory requests: remember or retrieve a named path or URL, and search or organize the operator's Vivaldi bookmarks when requested.

## Scope Gate

Resolve the intended memory action and source, then load `$SHIPGLOWS_ROOT/skills/references/intent-to-outcome-autonomy.md`. Supplying a path, URL, file, or bookmark for ordinary work is not permission to persist it; persistence requires explicit remember, keep, store, or bookmark intent.

## Required References

Resolve `$SHIPGLOWS_ROOT` through the shared canonical-path doctrine, verify the root and `$SHIPGLOWS_ROOT/skills/603-sg-private/SKILL.md` exist, then load that canonical engine. If the root or file is missing, stop with a visible error; never fall back to a sibling runtime path. Execute it end to end; `603-sg-private` remains an expert/internal engine only.

## Validation

Use the runtime engine's synthetic proof and private/public boundary checks. Never place real paths, URLs, notes, bookmark results, or backups in public Git evidence.

## Stop Conditions

When persistence intent is absent, treat the supplied value as transient and continue the original task without memorizing it. Stop only when persistence was requested but the value may contain a credential or secret, the requested source is unclear in a way that changes retention, or access would exceed the named private source.

## Report Modes

Load `$SHIPGLOWS_ROOT/skills/references/reporting-contract.md` before reporting. Keep private values in the operator conversation only when needed and keep internal engine names out of user-facing reports.
