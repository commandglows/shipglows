# Help — Quick Answers

Too many tasks → priorities then backlog defer. Unknown next step → priorities blockers. New idea mid-work → backlog. Before release → deploy. Outdated dependencies → technical deps; framework upgrade → technical migrate. New project → init. Research → research. For questions about rules, profiles, private data, questions, or reference discovery, load the corresponding canonical shared reference rather than paraphrasing it.

ShipGlows updates use an explicit target. Bare `shipglows update` changes nothing and lists the available commands. On Windows: `shipglows update runtime`, `shipglows update skills`, `shipglows update tools`, and `shipglows update status`. On Unix: `shipglows update runtime` and `shipglows update status`.
