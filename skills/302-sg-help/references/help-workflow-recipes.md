# Help — Workflow Recipes

For work planning: backlog → priorities → tasks → work → review. For a bug: `003-sg-bug` owns the durable BUG-ID loop; `107-sg-test` records evidence; `106-sg-fix` diagnoses; verify and ship gate closure. For a non-trivial build: spec → ready → start → verify → end/ship. For maintenance use `002`; for release use `004`; for content use `007`; for a global audit use `400`. Route rather than executing from help mode.
