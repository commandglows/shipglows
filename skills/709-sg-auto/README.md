# 709-sg-auto

Internal engine for the public `shipglows auto` mode.

The agent works alone to improve the current project's business across every
facet: product, technical quality, SEO, user experience, content, marketing,
performance, reliability, security and documentation. It picks the most
valuable evidence-backed improvement, delegates to the métier owner, proves the
slice with proportional local checks (lint, tests, managed dev sessions),
commits each validated milestone on the current branch, and continues without
waiting for the operator.

Unlike `shipglows blitz`, it has no time or credit pressure and runs local
proof. It never pushes, opens PRs, creates branches or worktrees, triggers CI,
deploys, touches production, publishes, spends money, or reveals secrets. It
asks the operator only when nothing else can progress without an
operator-owned decision, and batches those questions.

Operators should use `shipglows auto [focus]`, not the numeric engine name.
