# SEO Project Audit

Audit one web project end-to-end: crawlability/indexation, URL/site architecture and SEO-critical performance; systematic page table; content/intent/duplicate checks; valid schema; internal-link graph; then report. For large sites, inspect shared templates/layouts and representative page types rather than pretending every page was read. Include page counts, orphan/under-linked pages, schema coverage, score, proof gaps and governance plans. Audit remains read-only.
