# SEO Audit Protocol

SEO attracts the right user to a true promise. Start with business/brand/guideline metadata; stale, draft, missing or low-confidence contracts cap keyword/intent/claim confidence. Name missing business context as a proof gap, but continue bounded audit.

Before public content or mapped technical changes, load the editorial or technical corpus as applicable. Report Editorial, Claim and Documentation Update Plans when relevant. Claims about OpenAI/ChatGPT/current APIs/models/pricing require official current documentation; third-party AEO/GEO claims require current attributable sources. Never present fixed citation/adoption statistics as doctrine without fresh evidence.

Use traffic-first operational records and task-registry routing for follow-up: editorial work goes to editorial roadmap, technical work to tasks. Re-read a tracker before minimal write. Audit results are read-only and never authorize code/content changes.
