# SEO Page Audit

Read the target, layout/head injection, SEO defaults and sitemap context. Assess title/description/robots/canonical/lang/hreflang, social cards, heading hierarchy, intent/content truth, media alt/dimensions/loading, page-level technical SEO, internal links, schema and SEO-impacting performance. Check indexed claims against current product/docs. Report scored findings with exact files/lines, evidence limits and proposed fixes; do not modify a project in audit mode.
