# 708-sg-auto

Internal engine for the public `shipglows auto` mode.

It ranks safe, evidence-backed project work by durable value per wall-clock
minute, then advances candidates continuously under the mandatory implicit
no-local-execution policy. It freezes the launch root, coordinates claims with
other auto conversations, and recommends subagents for independent useful
missions. Model effort and agent count remain task-fit decisions, never ways to
consume credits artificially.

It may inspect and edit files inside the frozen root, but it never executes
project workloads, installs dependencies, commits, pushes, deploys, changes
Codex Fast settings, or claims verification.

Operators should use `shipglows auto`, not the numeric engine name. Add
`#nolocal` to an ordinary métier command when the objective is already selected
and only the no-local-execution restriction is wanted. The former
`shipglows nolocal <objective>` spelling remains a compatibility alias.
