# ShipGlows — Pitch

> Pitch reviewed: 2026-10-15 · Project state: see canonical sources below

A business framework that aligns humans and AI agents around shared business truth, from identity and product through delivery and proof, built first for solo founders and autonomous builders. The angle is governed intent and outcomes, with server and environment tooling as the execution layer rather than the headline.

## Current state

The repo holds the internal DX system (skills, CLI/DevServer, TUI, installers, tests), with the public site and SaaS moved to the separate shipglows_app repository, per the README and architecture docs updated in 2026-09 and 2026-10.
