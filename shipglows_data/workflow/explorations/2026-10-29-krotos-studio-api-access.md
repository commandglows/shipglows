# Exploration Report: Krotos Studio API access

## Question

Does Krotos Studio (audio sound-effects software, Krotos Ltd) offer a public API, SDK or scripting interface? If not, how could access be requested later?

## Findings

- **No public API found.** Neither the product page nor the roadmap mentions developer docs, an SDK, or a scripting interface.
- **Product surfaces:** standalone app (Windows/Mac), VST/AU/AAX plugins, and NLE plugins for Premiere Pro and DaVinci Resolve.
- **Roadmap (updated Jul 2026):** Pro Tools and Reaper integrations are planned.
- **Custom API/SDK:** a 2018 page on krotosaudio.com says Krotos licenses APIs and SDKs for B2B clients (games, VR/AR, apps) on a tailored basis. Not an open API. The page is old and needs re-checking.
- **Contact:** no contact address found in these sources. The route is krotos.studio.

## Limits

- Only public pages were checked. No account, documentation portal or support answer was reviewed.
- The 2018 statement about custom APIs may no longer reflect Krotos's current offer.
