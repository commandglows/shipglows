# Bug Record: BUG-2026-07-26-002

## Summary

- Title: Environment removal left runtime and indexes stale
- Current status: `fixed-pending-verify`
- Severity: `medium`
- Owner: ShipGlows
- Next command: `tests/cli/environment-remove.sh`

## Reproduction

- Preconditions:
  - A project has a local `.flox` environment.
  - The project may have a PM2 app or Flutter Web tmux session.
- Steps:
  1. Start or register the project runtime.
  2. Remove it through the Environments > Remove CLI action.
  3. Inspect the Flutter session registry, Caddy state, and ShipGlows environment registry.

## Expected Behavior

- Project files and all project-scoped runtime sessions are removed.
- PM2 and Caddy reflect the removal.
- Flutter Web session records and the durable ShipGlows registry no longer reference the project.
- Invalid absolute paths are rejected unless they contain a `.flox` project environment.

## Observed Behavior

- The project directory was removed, but the durable registry retained a stale line until a later refresh.
- Flutter Web sessions, Flox unregister, and Caddy cleanup were not part of `env_remove`.
- The absolute-path resolver accepted any existing directory.

## Evidence

- `cli/lib.sh::env_remove` and `cli/lib.sh::resolve_project_path_into`
- `tests/cli/environment-remove.sh`
- Local removal verification for `gocharbon_quiz` on 2026-07-26
