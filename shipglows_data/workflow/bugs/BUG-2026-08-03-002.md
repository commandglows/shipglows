# Bug Record: BUG-2026-08-03-002

## Summary

- Title: env_remove leaves manual project devservers running
- Current status: `closed`
- Severity: `high`
- Owner: Diane
- Next command: none

## Reproduction

- Preconditions:
  - A project is registered with ShipGlows.
  - A process started outside PM2 owns a TCP listening socket and has its cwd in the project tree.
- Steps:
  1. Start a manual TCP devserver from the project or a nested directory.
  2. Run `env_remove` for the project.
  3. Inspect the listener PID after the directory removal.

## Expected Behavior

- `env_remove` stops project-owned TCP listeners before deleting the directory.
- Processes that merely have a cwd in the project but own no TCP listener remain untouched.
- If a matched listener cannot be stopped, deletion fails before `rm -rf`.

## Observed Behavior

- Cleanup stopped registered PM2 and Flutter runtimes only; a manually launched devserver survived with a deleted cwd.

## Evidence

- Regression-first failure: `tests/cli/environment-remove.sh` reported `FAIL: manual TCP listener remains after environment removal`.
- Passing retest: `tests/cli/environment-remove.sh`.
- Syntax proof: `bash -n cli/lib.sh tests/cli/environment-remove.sh`.
