# Bug Record: BUG-2026-08-22-001

## Summary

A real first installation on a new Windows machine exposed independent fail-open and false-negative paths in the native bootstrap. Optional probes and version observations must be bounded and non-fatal, while installed-tool readiness must accept the exact output shapes produced by ShipGlows-owned installations.

## Expected Behavior

- An unusable optional WSL stub never stops the native installer.
- Corepack, pnpm, Flutter, Dart and Chromium observations terminate within a declared bound.
- Phase progress remains valid for long IDE and SDK installations.
- The environment report reflects executable evidence instead of brittle display formatting or object shape.
- A restart-required IDE outcome remains visibly pending until post-reboot observation proves readiness.

## Observed Behavior

- Executing `wsl.exe` could become a terminating native-command error.
- Direct Corepack/pnpm observations could wait indefinitely.
- `Math.Max(0, ticks)` selected an Int32 overload and overflowed on ordinary long installs.
- ShipGlows's detached Flutter checkout prints `channel [user-branch]` without a release number and abbreviates its framework revision (observed: `6655482ec0`); requiring a 40-character hash still classified a healthy SDK as partial.
- Playwright readiness assumed property shapes instead of normalizing metadata and executable paths.
- The full Android diagnostic repeated the release-only Flutter check, so a healthy detached managed SDK made the completed Android 36 toolchain appear pending.
- The managed Playwright package loop referenced a missing `Name` field after successfully installing Chromium.
- The Android 36 emulator image download grew to roughly 1.8 GiB while the installer promised visible progress but emitted none.
- Android Studio requested a restart but was absent after reboot; no source correction is claimed until a branch retest captures the provider result.

## Proof Path

`regression-first`: PowerShell parser checks, focused installer-engine/mobile/Playwright/bootstrap regressions, the Windows contract, then a real branch-archive full install and idempotent rerun.
