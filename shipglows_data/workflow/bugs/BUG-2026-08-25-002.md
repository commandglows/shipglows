# Bug Record: BUG-2026-08-25-002

## Summary

- Current status: `closed`
- Expected: every exact machine CLI either converges independently or remains explicitly pending.
- Observed: Clerk 3.2.0 remained absent and its stable wrapper exited 127 after the aggregate toolbox installation.

## Reproduction

1. Configure the machine toolbox with `npm:clerk = "3.2.0"` while only Clerk 3.1.0 is installed.
2. Run the full Windows installer.
3. Observe `mise ls`: Clerk 3.2.0 is selected but missing.
4. Run `clerk.cmd --version`; it exits 127.
