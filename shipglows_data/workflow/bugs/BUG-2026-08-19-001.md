# Bug Record: BUG-2026-08-19-001

## Summary

- Title: CLI always reports low RAM on VMs smaller than its absolute threshold
- Current status: `closed`
- Severity: `medium`
- Owner: unassigned
- Next command: none

## Reproduction

- Preconditions:
  - Before the fix, a Linux VM had less total RAM than the former default `SHIPGLOWS_MEM_WARN_GB=4` threshold.
- Steps:
  1. Start the ShipGlows CLI on a VM with 3.7 GiB total RAM.
  2. Observe that approximately 1.8 GiB, or 48%, remains available.
  3. Observe the low-memory warning in the menu header.

## Expected Behavior

- Memory severity reflects the proportion of RAM still available; lack of swap is reported as a separate capacity-risk signal.

## Observed Behavior

- Any available-memory value on a VM smaller than 4 GiB is below the absolute default threshold, so the CLI permanently reports low memory.

## Evidence

- `/proc/meminfo`: 3,911,564 kB total and approximately 1,907,280 kB available during diagnosis.
- `cli/lib.sh`: `mem_is_low` compares available RAM with a default absolute 4 GiB threshold.
- No secrets, private payloads, or personal data were collected.
