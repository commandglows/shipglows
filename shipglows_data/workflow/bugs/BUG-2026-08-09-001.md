# Bug Record: BUG-2026-08-09-001

## Summary

- Title: Full installer cannot install PM2 with Node 24
- Current status: `fix-attempted`
- Severity: `medium`
- Owner: Diane
- Next step: Run the focused regression test and a fresh full-install retest.

## Reproduction

- Preconditions: Fresh Ubuntu 24.04 server with no Node.js, pnpm, or PM2 installation.
- Steps:
  1. Run the public ShipGlows full installer.
  2. Let it install Node 24.
  3. Observe the PM2 installation stage.

## Expected Behavior

- Corepack exposes pnpm on `PATH` and the installer installs PM2 successfully.

## Observed Behavior

- Node 24.19.0 installs, then PM2 installation fails because pnpm is not enabled or `PNPM_HOME/bin` is absent from `PATH`.

## Evidence

- Redacted sandbox installer log: Node installation passed; PM2 installation failed.
- `corepack prepare pnpm@latest --activate` alone left `pnpm` unavailable on Node 24.
- After `corepack enable`, pnpm required its user-local `PNPM_HOME/bin` directory on `PATH`.
