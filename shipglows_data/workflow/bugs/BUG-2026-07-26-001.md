# Bug Record: BUG-2026-07-26-001

## Summary

- Title: GitHub deployment cannot start a newly cloned Flox project
- Current status: `fix-attempted`
- Severity: `medium`
- Owner: unassigned
- Next step: Run the focused GitHub deployment regression test and CLI checks.

## Reproduction

- Preconditions:
  - A repository is not already in the environment registry.
  - Deploy from GitHub is selected in the DevServer.
- Steps:
  1. Select a repository, such as `gocharbon_quiz`.
  2. Let ShipGlows clone it and initialize `.flox`.
  3. Observe the application-start step.

## Expected Behavior

- The newly cloned project starts successfully and becomes visible in the environment registry.

## Observed Behavior

- Clone and Flox initialization succeed, but startup reports `Projet introuvable pour l'identifiant: gocharbon_quiz`.

## Evidence

- Operator-provided terminal output, redacted of no sensitive data.
- Focused automated regression: `tests/cli/github-deploy-path-resolution.sh`.
