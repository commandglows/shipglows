## Reproduction

- Preconditions:
  - Windows PowerShell receives `local/install_local.ps1` from the public Windows bootstrap.
- Steps:
  1. Run the installer from `C:\Users\Shadow\shipglowz`.
  2. Inspect or execute the generated tunnel/profile PowerShell.
  3. Observe escaped variables, shell color syntax, or mojibake.
- Expected: Every `.ps1` file parses and runs natively in PowerShell without WSL, Bash, or sudo.
- Observed: The generated script contained PowerShell-invalid escaped variables and shell-style color expressions.
